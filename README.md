# APNEA AI – Машинное обучение для классификации эпох ПСГ (Раздел 2.6)

**APNEA AI** – это программный модуль для автоматической классификации 30‑секундных эпох сна (N2/N3) на «апноэ/гипопноэ» и «без событий» с использованием методов машинного обучения. Модуль реализует задачи, описанные в **разделе 2.6** диссертационной работы.

## 🎯 Основные возможности

- **Загрузка данных** из REST API (полисомнографические исследования, эпохи, клинические данные).
- **Фильтрация** исследований по возрасту, AHI, типу апноэ.
- **Подготовка признаков** (пациент-специфическая z‑нормализация, удаление пропусков).
- **Обучение моделей**:
  - Логистическая регрессия
  - Random Forest
  - XGBoost (с поддержкой CUDA при наличии NVIDIA GPU)
  - MLP (многослойный перцептрон)
- **Групповая кросс-валидация** по пациентам (GroupKFold) – предотвращает утечку данных.
- **Подбор гиперпараметров** (опционально GridSearchCV).
- **Оценка моделей** (AUC, F1, чувствительность, специфичность, balanced accuracy).
- **Визуализация**:
  - ROC‑кривые и Precision‑Recall кривые
  - Confusion matrix
  - Calibration curve
  - Feature importance
  - SHAP summary и dependence plots
  - t‑SNE проекция признаков
- **Сохранение** обученных моделей (joblib) и графиков (PNG).
- **Генерация HTML‑отчёта** со всеми метриками и графиками.

## 🔧 Установка и запуск

### Требования
- Python 3.14+
- NVIDIA GPU (опционально, для ускорения XGBoost и PyTorch)
- Доступ к API‑серверу с данными ПСГ

### Установка зависимостей

```bash
git clone https://github.com/Psy66/PSG_analise_ml.git
cd PSG_analise_ml
pip install -r requirements_ml.txt
```

Если у вас есть NVIDIA GPU и CUDA, установите PyTorch с поддержкой CUDA:
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```

### Запуск

```bash
python main_ml.py
```

## 📖 Инструкция по использованию

1. **Вкладка «Загрузка и настройки»**
   - Введите адрес API (например, `https://med.smed96.synology.me/psgapp/api/`) и ваш токен.
   - Выберите **тип эпох** (рекомендуется `1` – тонические эпохи N2/N3).
   - Выберите **задачу**: `Классификация эпох (has_apnea)` – основная задача.
   - Установите **нормализацию**: `Пациент-специфическая (z‑score)`.
   - При необходимости измените размер тестовой выборки (по умолчанию 20%).
   - Нажмите **«Загрузить данные и подготовить выборку»**.

2. **Вкладка «Обучение и оценка»**
   - Отметьте модели, которые хотите обучить (можно все).
   - Выберите число фолдов кросс-валидации (по умолчанию 5).
   - При желании включите **«Подбор гиперпараметров (GridSearchCV)»** (может занять время).
   - Нажмите **«Запустить обучение»**.
   - После завершения появятся таблица метрик и графики (ROC, PR, confusion matrix, calibration curve).

3. **Вкладка «Интерпретация и отчёт»**
   - Выберите обученную модель из списка.
   - Нажмите **«Рассчитать SHAP»** (может занять 1–2 минуты).
   - Нажмите **«Построить t‑SNE»** для визуализации разделимости выборки.
   - Кнопка **«Сохранить графики (PNG)»** сохранит все текущие графики в папку.
   - Кнопка **«Сформировать HTML‑отчёт»** создаст полноценный отчёт с метриками и графиками.
